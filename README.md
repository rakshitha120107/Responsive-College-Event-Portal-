# Spectra 2026 - College Event Portal
Prathyusha Engineering College

## Features
Homepage, About, Event Listings (category filter), Registration Form (validation), Gallery (photo upload), Contact, responsive design, dark mode.

## Run
Open `index.html` in a browser. No install needed.

## Files
- index.html - page structure
- style.css - responsive styles
- script.js - events data, page rendering, filters, form validation, gallery
- photos/ - put college photos here

## Tech
HTML5, CSS3 (Grid/Flexbox, media queries), JavaScript DOM manipulation.
